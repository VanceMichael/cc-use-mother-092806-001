# 领域边界

管理洪灾撤离、安置容量、家庭团聚、敏感需求和救助物资。

现有领域资料围绕以下边界组织：

- 家庭与人员核验
- 撤离和安置容量
- 寻亲团聚
- 物资批次守恒
- 隐私与恢复待办

资料版本只能递增。参与方、事实和约束均不能为空，示例不得包含真实个人信息、账号或凭据。

## 已落地的领域规则

### 家庭与人员核验

- 无证件人员接收后进入 `pending_verification`；补证件或经人工确认依据后才可核验。
- 同一证件号指向不同档案属于内容冲突，不自动核验，转人工复核单。
- 档案合并把被合并档案的**最初接收事实**（时间、安置点）原样并入存活档案，
  并标记 `via_merge`；合并不自动改变待核实状态。
- 合并时姓名不兼容或分属不同家庭，转人工复核，不自动合并。
- 家庭关系随合并重映射；人员位置轨迹与领用记录归并到存活档案。

### 撤离和安置容量

- 安排类型：普通转运、医疗转运（透析等，仅医疗岗）、出院、返家、跨区调剂（仅协调岗）。
- 安排状态机 `pending → confirmed → executed`，另有 `cancelled`；
  变更与取消只能作用于 pending/confirmed。
- 同一人员同时只能有一条未完成安排。
- 入住率 ≥ 90% 开容量预警，回落自动解除；普通转运不得进入满员点，
  医疗转运可确认但执行仍受硬容量拦截。

### 寻亲团聚

- 寻亲记录按姓名、同家庭关系与称谓、线索文本自动给候选及匹配依据。
- 自动结果只是建议；团聚必须由儿童福利岗或协调岗人工确认，且必须提供依据。
- 团聚依据与确认人、时间一起留痕，可在家庭时点视图回放。

### 物资批次守恒

- 物资与药品批次分别记数量与已发/已发药数量，发放不得超存量。
- 已发物资只能通过退回（冲减、原记录保留）或补发（新批次再出、关联原记录）调整。
- 回执编号重复时直接返回首次决定，不二次扣减；命令幂等键同理。
- 药品可用存量低于阈值自动开补给待办，到货自动了结且不重复开单。

### 隐私与恢复待办

- 健康信息仅医疗岗可见；儿童年龄/未成年标记仅儿童福利岗与医疗岗可见。
- 全部状态由事件日志回放得到；重启后 `/ops/recover` 汇总开放容量预警、
  药品补给、开放寻亲、待确认/待执行安排与人工复核单。
- pending 安排超过 24 小时进入超期待确认列表。
- 日志崩溃留下的半截末行在重新打开时截断修复，序号保持连续。
